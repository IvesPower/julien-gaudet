# Lot 1 — Socle en ligne : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** mettre en ligne sur `*.vercel.app` un projet Next.js 16 bilingue (URLs traduites), sans design, avec une CI bloquante et des previews par branche.

**Architecture :** projet généré par `create-next-app` puis outillé (Oxlint, Prettier, Vitest, playwright-bdd). Le routage passe par `next-intl` v4 : une table `pathnames` traduit les chemins internes (dossiers en français sous `app/[locale]/`) en URLs FR / EN ; `proxy.ts` gère la détection de langue sur `/`. Toutes les pages sont statiques (`generateStaticParams` + `setRequestLocale`) et lisent leurs textes dans `messages/*.json`.

**Tech stack :** Node 26 LTS, pnpm 12, Next.js 16.4, React 19, TypeScript (version installée par `create-next-app`), next-intl 4.15, Oxlint 1.94 (+ `oxlint-tsgolint`), Prettier 3, Vitest 5, Playwright 1.65 + playwright-bdd 9 + `@axe-core/playwright` 4, GitHub Actions, Vercel (intégration Git).

**Spec :** [docs/superpowers/specs/2026-11-22-lot-1-socle-design.md](../specs/2026-11-22-lot-1-socle-design.md). Brief local, non versionné : `julien-gaudet - Document de conception.md`.

Versions vérifiées le 22 novembre 2026 : npm (`next` 16.4.6, `next-intl` 4.15.3, `oxlint` 1.94.0, `vitest` 5.1.1, `@playwright/test` 1.65.1, `playwright-bdd` 9.2.1, `@axe-core/playwright` 4.14.0, `prettier` 3.10.1, `pnpm` 12.21.0), nodejs.org (Node 26.13.1 LTS), GitHub (`actions/checkout@v7`, `actions/setup-node@v7`, `pnpm/action-setup@v6`).

## Global Constraints

- TypeScript strict, aucun `any`. Code, commentaires, noms de tests, scénarios Gherkin et messages de log en anglais ; textes du site en français et en anglais, uniquement dans `messages/fr.json` et `messages/en.json`.
- Aucun style : pas de CSS, de tokens, de polices ni de Tailwind dans ce lot. Le `globals.css` et les styles générés par `create-next-app` sont supprimés.
- Toutes les pages sous `app/[locale]/` sont générées statiquement. Une route listée `ƒ` (dynamique) dans la sortie de `pnpm build` est un échec.
- JavaScript client : seul le sélecteur de langue est un Client Component.
- Node `26.x` (`package.json` `engines`, `.nvmrc` = `26`), `packageManager` = `pnpm@12.21.0`.
- Langues `fr` (par défaut) et `en`, préfixe toujours présent (`localePrefix: 'always'`).
- Table des chemins, exactement :

  | Interne | FR | EN |
  | --- | --- | --- |
  | `/` | `/fr` | `/en` |
  | `/parcours` | `/fr/parcours` | `/en/experience` |
  | `/projets` | `/fr/projets` | `/en/projects` |
  | `/projets/[slug]` | `/fr/projets/[slug]` | `/en/projects/[slug]` |
  | `/photo` | `/fr/photo` | `/en/photo` |
  | `/conferences` | `/fr/conferences` | `/en/talks` |
  | `/conferences/[slug]` | `/fr/conferences/[slug]` | `/en/talks/[slug]` |
  | `/podcast` | `/fr/podcast` | `/en/podcast` |
  | `/mentions-legales` | `/fr/mentions-legales` | `/en/legal-notice` |

- Cookie de langue : `NEXT_LOCALE`, comportement par défaut de next-intl v4, `maxAge` = `31536000` (un an).
- `/` est la seule URL redirigée selon la langue (cookie, puis `Accept-Language` avec pondérations, sinon `fr`). Une URL préfixée n'est jamais redirigée vers une autre langue.
- Chaque page déclare `hreflang` `fr`, `en` et `x-default` (= `/`).
- Git : branches `type/…`, commits `type(scope): English / français` + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, PR bilingues (`## TL;DR`, `## Changes` / `## Changements`, `## Testing` / `## Vérifications`, séparées par `---`) terminées par `🤖 Generated with [Claude Code](https://claude.com/claude-code)`. Seul le commit de la tâche 1 va directement sur `main`.
- Le document de conception et `.claude/settings.local.json` ne sont jamais commités.

## Review Focus

1. **URL dans la mauvaise langue tapée à la main** (`/en/conferences`, `/fr/talks`) : on attend une redirection vers l'URL correcte de la même langue (`/en/talks`), pas une 404 ni un changement de langue. Test : tâche 4, scénario « Internal pathname in the wrong language ».
2. **Variante régionale du navigateur** (`Accept-Language: en-GB`, `fr-CA`) : `/` doit mener à `/en` ou `/fr`. Test : tâche 4, lignes d'exemples du scénario de redirection.
3. **Slash final** (`/fr/conferences/`) : on attend une redirection vers `/fr/conferences`, pas une 404. Test : tâche 4.
4. **Page devenue dynamique sans qu'on le voie** (oubli de `setRequestLocale`, lecture de `headers()`) : le build doit échouer. Test : tâche 5, script `check:static` lancé en CI.
5. **Clé de traduction présente dans une langue et absente de l'autre** : le typecheck ou Vitest doit échouer. Test : tâche 4, `messages.test.ts`.
