- Retrouve chaque réplique dans les sous-titres VF, ou dans le doublage grâce à Whisper.
- Coupes calées sur les phrases, fondus et son de transition.
- Choisit la piste VF (ou VFF/VFQ), normalise à -16 LUFS.
- Sorties WAV 48 kHz, MP4 H.264 et index `clips.json` ; seuls les extraits modifiés sont refaits.
- Claude en option pour proposer les coupes ; fonctionne sans.
