# julien-gaudet

## English

Personal bilingual (FR / EN) business-card site of Julien Gaudet, built with Next.js (App Router) and strict TypeScript. It is generated at build time and deployed on Vercel: https://julien-gaudet.vercel.app

### Main commands

Node and pnpm versions, the full list of commands and the project conventions are in [CLAUDE.md](CLAUDE.md).

- `pnpm dev`: development server.
- `pnpm build` then `pnpm start`: production build and local server.
- `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`: checks.
- `pnpm photos:meta <folder>`: syncs a folder of original photos with the site (see [docs/features/photos.md](docs/features/photos.md), in French).
